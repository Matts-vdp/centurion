Markup

Collapsed details new child: <More>

A card or an item gets a chevron; the details open in place. The list stays scannable, and the reasoning is one click away instead of a paragraph under every line.

A step in a flow can hide its details too. Collapsed by default; an agent can't make it open. A <More> holds text and <Code>, never cards, so it never hides structure.

Markup

Small extras on a card attributes: meta, change, progress

meta is quiet text on the right (a time, a size, a line number). change sits next to a key number. progress is a thin meter, 0–100 or 3/5. Tone colours them, as it does the icon and the number now.

Markup

Bar chart new element: <Bars> with <Bar>

Comparing a handful of numbers. No axes or legend: it scales to the largest value and writes the number on each bar. Neutral grey unless a tone says something.

Markup

Tree new element: <Tree> with nested <Item>

For anything hierarchical: a proposed folder structure, a component tree, the shape of a config, or a call tree in an investigation (see the example at the top). Click a row with a chevron to fold it. A folded row says how much it hides. collapsed lets the agent start a large branch folded.

New things use tone="accent" (the tone that already means "the new or recommended thing"), so their icon turns aqua. A move or a removal is said in words with meta.

Links are optional per item, so existing and planned code mix in one tree. An item with link="file:path:line" opens that file at that line: a leaf row opens when you click it, and a row with children shows the location on the right (click it to open, click the row to fold). Items without a link (new files, library calls) are plain lines. The tool checks that every linked file exists.

Markup

Images new element: <Image>

A screenshot or chart the agent made, from its folder. Two in a Row are a before/after; clicking one opens it full size in the Files panel.

Markup

Timeline new element: <Timeline> with <Item when>

What happened, or what comes next: an incident, a run, the PRs of a plan. The dots take the tone. Items after the running one are still to come and get a hollow dot.

Markup

Code new element: <Code>

A short excerpt, up to about 25 lines, taken literally up to </Code>. With file and line it gets a header that opens the file at that line, and real line numbers. mark highlights the lines that matter. lang="diff" shows a change in one block. It can go in a card or in a <More>.

When file and line are given, the tool compares the excerpt with the file and warns the agent if they don't match, which catches made-up or stale evidence.
